## Что внутри файла (карта для тебя)

Смещения — в байтах от начала файла, ASCII-строки, `\0`-разделённые:

| Offset | Что |
| --- | --- |
| `0x0` | `a7 00 00 00 00 00 00 00 42 10 00 00` — заголовок |
| `0x3698` | `caption choose caption stringz medved_name` |
| `0x3739` | `font_name choose font_name stringz menu` ← **дефолт `menu`** |
| `0x3739+…` | `font_color color, u32`, `font_sym_color`, `font_symt_color`, `font_size fp32`, `line_spacing u8`, `advanced bool` |
| `0x4B …` | пул `font\font_*`, `ui\ui_*` (интернированные пути) |

Начало файла: `ui_nickname\0 03 on_activate\0 choose\0 on_activate\0 stringz\0`
— таблица «имя свойства → тип → варианты», дальше записи значений.

Это меняет картину: **элемент меню не «пустой» — у него есть схема со
значением по умолчанию `menu`**, просто мод, создавая caption-элемент,
кладёт в `font_name` не `menu`, а что-то другое (или пустую строку, и exe
подставляет `arial`). Проверяется по смещению поля.
