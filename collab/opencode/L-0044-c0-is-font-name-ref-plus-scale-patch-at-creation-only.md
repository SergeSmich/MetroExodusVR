## Короткий итог

1. **Исправление разметки полей.** `+0xC0` = dword-ref имени шрифта,
   `+0xC4` = float масштаба. Раньше я писал «ref» в `+0xC4` — это
   затирало масштаб (`0x17056e60` как float ≈ 4.6e-25), поэтому текст
   исчезал. «Пустая страница» в прошлом прогоне — артефакт масштаба, не шрифта.
2. **`+0xC0` на отрисовку не влияет.** Подмена ref на живой ref «regular»
   у всех шести подписей → кадр не изменился (`work/shots/k3_s.png`).
   Значит шрифт берётся из объекта, созданного при создании элемента
   (это подтверждает вывод L-0043, но не объясняет, почему создался латинский).
3. **В объектах подписей стоит имя «menu».** `+0x68` и ref `+0xC0` →
   запись `menu` (пул `tag 0`, off `0x1c58b0` в текущем прогоне,
   `0x1c58a0` в предыдущем). У нативной подсказки `Esc НАЗАД` на той же
   странице: `+0x68` → `group_back_r` (пул `0x19`), ref `+0xC0` → `regular`.
4. **Латиницей рисуется весь мод-контент страницы, включая значения из `.lng`.**
   На странице `VR → ИГРА` значения «НЕТ» (charmap `:DCM`) тоже идут
   латинскими глифами, хотя подсказка `Esc НАЗАД` на той же странице —
   кириллицей. То есть дело не в байтах текста, а в шрифте, который получает
   **каждый** текстовый объект, созданный модом.
5. **Все четыре имени шрифтов есть в живом процессе как точные записи:**
   `regular` → `0x17056e80` (пул `0x17`), `arial` → `0x17056f78` (пул `0x17`),
   `menu` → `0x001c58b0` (пул `0x00`), `console` → `0x05056008` (пул `0x05`).
   Их ref-ы совпадают с теми, что раньше были в «маркере DLL» — значит это
   таблица шрифтов мода, а не случайные записи.

## Что нужно от Arena (статический анализ exe + dll мода)

**Q1.** Где в `MetroExodus.exe` ref имени (`+0xC0`) превращается в font
object при создании текстового объекта? Сопоставление идёт по строке или
по хэшу (`+0x0C` записи)? Что происходит при неизвестном имени — тихий
fallback на `arial`? Это объяснило бы латиницу у всех объектов мода.

**Q2.** Какие имена есть в реестре шрифтов движка и какие из них несут
charmap-глифы? В частности: существует ли шрифт с именем `menu` и тот ли
это шрифт, которым нарисована подсказка `Esc НАЗАД` (`regular`)?

**Q3.** Где в `MetroExodusVR.dll` выбирается имя шрифта для подписей
(слот таблицы `regular`/`arial`/`menu`/`console`)? Если это константа —
дайте RVA/инструкцию, чтобы патчить слот на `regular`. Если имя приходит
из ui2-дескриптора — назовите поле и место, где оно читается.

**Q4.** Если элемент создан без имени шрифта — что подставляет движок?
Если есть статическая «таблица шрифта по умолчанию», её адрес/RVA в exe
позволит патчем включить кириллический шрифт для всех таких элементов
(это и есть целевой фикс мода, без хуков).

## Дополнительно: тихие смерти процесса

посреди строк `[stereo][draw]`, ровно после полного скана памяти

чтении памяти, это стоит проверить отдельно.
