# modkit — запуск игры с оригинальным модом и с нашим переводом

Коротко: **всё делается двойным кликом по `.cmd` в этой папке**
(`F:\Projects\MetroExodusVR\work\modkit`). Руками ничего не копируется.

Файл ставит нужный билд в игру, проверяет его по sha и сам запускает игру.

| Двойной клик | Что будет |
| --- | --- |
| `0-СОСТОЯНИЕ.cmd` | только показывает, что сейчас стоит в игре |
| `1-ОРИГИНАЛ-МОД.cmd` | ставит **оригинальный мод 0.9.3** (английский) и запускает игру |
| `2-НАШ-ПРОЕКТ.cmd` | ставит **наш проект** (мод 0.9.3 + перевод A/C) и запускает игру |
| `3-ЧИСТАЯ-ИГРА.cmd` | убирает мод из игры и запускает **чистую игру** |
| `4-СОХРАНИТЬ-ЛОГИ.cmd` | сохраняет логи последнего прогона (спросит, что было на экране) |

Окно консоли закрывать не обязательно, оно само ждёт нажатия клавиши.
При переключении билда логи прошлого прогона сохраняются автоматически.

## 1. Прогон «оригинальный мод»

1. Игра закрыта. Двойной клик **`1-ОРИГИНАЛ-МОД.cmd`**.
2. В консоли должно быть `готово. установлено: Оригинальный мод 0.9.3`, затем
   игра запустится сама.
3. Когда появится окно «4A Engine» — **один клик внутрь окна** (чтобы оно было
   в фокусе), дальше не переключайся на другие окна и не двигай его.
4. В игре: `SETTINGS → VR → GRAPHICS`. Страница должна открыться, интерфейс английский.
5. Выйти из игры через меню (не убивать процесс).
6. Логи сохранятся сами при следующем переключении. Если хочешь сохранить
   сразу — двойной клик `4-СОХРАНИТЬ-ЛОГИ.cmd`, напиши пару слов, что видел.

## 2. Прогон «наш проект»

1. Игра закрыта. Двойной клик **`2-НАШ-ПРОЕКТ.cmd`**.
2. В консоли должно быть `готово. установлено: Наш проект: мод 0.9.3 + правки перевода A/C`,
   затем игра запустится сама.
3. Один клик внутрь окна «4A Engine», не переключаться.
4. В игре: `НАСТРОЙКИ → VR → ГРАФИКА`. Должна открыться страница с кириллицей
   без «квадратов»: `РЕЖИМ РЕНДЕРА`, `СТЕРЕО`, `ВЫКЛ (TAA)`, `АВТО (K)`,
   `МАСШТАБ РЕНДЕРА`, `АПСКЕЙЛЕР`, `РЕЗКОСТЬ FSR`, `МОДЕЛЬ DLSS`.
   Заодно открыть `КОМФОРТ`, `УПРАВЛЕНИЕ`, `КАМЕРА` — там та же механика.
5. Выйти через меню.

## 3. Прогон «чистая игра» (для сравнения)

Двойной клик **`3-ЧИСТАЯ-ИГРА.cmd`** → мод убирается, запускается `MetroExodus.exe`
без мода. Меню мода (VR) в этом режиме нет — это нормально.

## 4. Что откуда берётся

| Что | Где лежит | Кто трогает |
| --- | --- | --- |
| Игра | `F:\SteamLibrary\steamapps\common\Metro Exodus` | скрипт ставит/снимает только мод-файлы |
| Оригинальный мод 0.9.3 | `E:\MetroExodusVR` (эталон, не менять) | скрипт читает |
| Наш перевод | `F:\Projects\MetroExodusVR\build\MetroExodusVR-0.9.3.dll` | скрипт читает |
| Профили | `work\modkit\profiles.json` | правится только если меняется путь/сборка |
| Снятые файлы | `work\modkit\archive\<дата>-*\` | скрипт, ничего не удаляет |
| Логи прогонов | `work\modkit\runs\<дата>-auto\` | скрипт |

«Оригинал» = чистая поставка из `E:\MetroExodusVR` + её родная DLL.
«Наш проект» = та же поставка + наша DLL (единственное отличие).

## 5. Что именно делает скрипт

```
MetroExodusVR.exe          <- копия стаба из поставки
updater.json               <- пишется заново: mode=never, pinned=0.9.3
versions\0.9.3\            <- лаунчер, стаб, лицензии + нужная DLL
logs\                      <- создаётся пустой
```

Проверки после установки: sha DLL, sha стаба, `version.json` = 0.9.3,
`updater.json` = `mode=never`. При несовпадении — ошибка, а не молчаливая поломка.
Перед переключением скрипт отказывается работать, если игра запущена.

## 6. Команды (если нужен терминал, а не кнопки)

```powershell
cd F:\Projects\MetroExodusVR
$env:PYTHONIOENCODING='utf-8'; python -u -X utf8 work\modkit\mod_switch.py status
```

`status`, `apply orig`, `apply ours`, `clean --yes`, `verify`, `collect [id] --shots --note "..."`,
`autocollect`, `purge [--keep N] --yes`, `hashes` — подробности в `--help`.

## 7. Если что-то пошло не так

| Симптом | Что делать |
| --- | --- |
| `НЕ ПОЛУЧИЛОСЬ...` в консоли | игра ещё запущена — закрыть игру, запустить `.cmd` снова |
| игра не стартует после `apply` | `0-СОСТОЯНИЕ.cmd`: если `режим: VANILLA` — билд не встал, повторить |
| чёрный экран | профиль тут не виноват (проверено), писать агенту, логи уже сохранены |
| `verify` пишет `FAIL` | стаб подменил DLL, повторить установку того же `.cmd` |
| нужно освободить место | `python -u -X utf8 work\modkit\mod_switch.py purge --keep 2 --yes` |
