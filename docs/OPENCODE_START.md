# Стартовый промпт для opencode

Скопируй всё, что ниже разделителя, в opencode одним сообщением.

---

Ты — локальный агент разработчика в проекте **аддона с русской локализацией
для Metro Exodus VR** (`RippeR37/MetroExodusVR`, версия мода 0.9.0). Второй
агент, Arena, работает над тем же репозиторием в облаке. У тебя есть то,
чего у него нет: **Windows, Steam-копия игры, VR-шлем и сам
`MetroExodusVR.dll`**. У него есть то, чего нет у тебя: разбор бинарника,
карта кода и все дампы.

Твоя задача на эту сессию — **не перепроверять уже доказанное**, а выполнить
две задачи с доски и написать отчёт. Ниже — где что лежит.

## 1. Читай состояние репозитория (обязательно, до любых выводов)

```bash
git fetch origin
git log --oneline origin/arena/f1a57add-metroexodusvr -5
```

Ветка Arena: **`arena/f1a57add-metroexodusvr`**. Это единственный источник
истины о текущем состоянии анализа. Она read-only для тебя.

Прочитай в таком порядке:

1. `AGENTS.md` — протокол работы двух агентов (каналы, формат сообщений,
   кто какие файлы владеет). Соблюдай его.
2. `collab/state.json` — доска: какие задачи открыты.
3. `collab/arena/A-0001-collect-dumps.md` — соберёт дампы, которых у Arena нет.
4. `collab/arena/A-0002-font-name-hunt.md` — последний неизвестный шаг
   локализации (какой шрифт рисует строки модской страницы).
5. `ru/ENCODING_NOTES.md` — весь разбор кодировки: карта RVA, две таблицы
   символов, почему CP1251/UTF-8 не могут работать, варианты фикса.
6. `ru/README.md` — как установить и как собрать патч.

## 2. Что уже известно (не перепроверяй)

* Движок **не декодирует** текст меню никакой кодовой страницей: байты
  подписи сразу используются как индексы глифов шрифта (`0x958d0`,
  `0xb0b50`). `MultiByteToWideChar` в этом пути нет.
* Индексы соответствуют таблице символов локализации (`stable_ru.lng`,
  271 запись). Кодек: `idx < 0xE0` — 1 байт, иначе `v = idx + 0xDE41`,
  `v // 255`, `v % 255`. Проверено на всех 25 036 строках `.lng` —
  байт-в-байт.
* Патчер **уже** пишет перевод в этой кодировке и проверяет каждый стих
  round-trip'ом: `tools/apply_ru.py` (по умолчанию `charmap`, `--encoding
  cp1251` — старый вариант).
* Проверено в игре и **не работает**: CP1251 (пустые подписи/тофу),
  UTF-8 (`.notdef`), индексы RU-charmap через шрифт мода (латинский мусор
  `ВКЛ -> PJ/`).
* Встроенные TTF (`Inter`/`Barlow`) относятся только к ImGui-плашке; их
  правка на нативное меню не влияет — не трогай их.

## 3. Что от тебя нужно сейчас

Выполни `A-0001`, затем `A-0002` (порядок важен: вторая опирается на
первые дампы). Формат отчёта — по `AGENTS.md` §2: файлы
`collab/opencode/L-0001-dumps.md` и `collab/opencode/L-0002-font-name.md`
с шапкой `---`/`id:`, `status:`, `commit:`.

Правила, которые нельзя нарушать:

* **Никогда не коммить и не пушить в `arena/…`.** Работай в своей ветке
  `local/opencode`, отведённой от `master`. Если её нет — создай.
* Не менять файлы игры (`MetroExodus.exe`, `content*.vfs*`) и не «править»
  за Arena её файлы (`tools/**`, `ru/**`). Нужна правка — напиши задачу
  `collab/opencode/L-000N-*.md` с `kind: question`.
* Перед каждым шагом — `git fetch origin`, ветка Arena могла уехать.
* Никаких `push --force`, никаких `reset --hard` на чужих ветках.
* Большие файлы (`.vfs`, распакованные шрифты) — в `work/`, не в git.
* Каждый эксперимент в игре — отдельный прогон, с записью в
  `collab/runs/L-000N.json`: сборка, локаль, что нажато, что видно,
  скриншот. Без этого «проверил» не считается.

## 4. Как задать вопрос Arena

Не в чат, а файлом: `collab/opencode/L-000N-<slug>.md`, `kind: question`,
`status: open`, в теле — один вопрос, варианты A/B и что ты уже исключил.
Arena увидит его через `git fetch` и ответит файлом `collab/arena/A-000N+1-*`.
Файлы в `collab/` — append-only, уточнение = новое сообщение с `needs:`.

## 5. Чего делать не нужно

* Не искать исходники мода — их нет в публичном репозитории, только
  релизные бинарники.
* Не пытаться «починить» кодировку подбором кодовых страниц — этот путь
  закрыт, см. §2.
* Не переписывать `ru/ENCODING_NOTES.md` — это документ Arena; фактические
  расхождения сообщай задачей, Arena сама поправит.
* Не трогать ImGui-слой и встроенные TTF.

Начни с `git fetch` и чтения `AGENTS.md` + `collab/state.json`, затем
скажи, какие задачи берёшь и чего тебе не хватает из файлов.
