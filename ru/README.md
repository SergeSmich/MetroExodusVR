# Русский перевод Metro Exodus VR

Перевод нативных меню, настроек, подсказок и всплывающих окон VR-мода
`MetroExodusVR.dll`. Оригинальные файлы игры (`MetroExodus.exe`, `content.vfx`
и т. д.) не изменяются.

## Что переведено

* Подписи страниц меню и настроек игры, включая VR-раздел (193 строки,
  `ru/strings.tsv`).
* Всплывающие окна (popups), параметры (options), HUD-подсказки (hints) и
  страницы «VR HINTS» (14 вкладок) — `ru/ui2.json`.
* Строки встроены в новую PE-секцию `.ru`; оригинальные английские литералы
  остаются нетронутыми, поэтому общие строки движка (`TAA`, `DLSS`, `FSR`,
  `OFF` и т. п.) не ломаются.

Не переводится (по решению): отладочный ImGui-оверлей (метрики, camera
authority, body/hands debug, dev-хоткеи) и подпись «Opened in your browser» на
плашке со ссылками. Для кириллицы в ImGui потребовалась бы замена встроенных
шрифтов Inter/Barlow.

## Требования

* Windows, Python 3.10+.
* Python-пакет `capstone` (используется патчером):
  `python -m pip install capstone`.
* Установленный мод Metro Exodus VR (папка `versions\<версия>\MetroExodusVR.dll`).

## Установка

1. Распакуйте релиз мода в папку игры, например
   `F:\SteamLibrary\steamapps\common\Metro Exodus`
   (рядом с `MetroExodus.exe` должны появиться `MetroExodusVR.exe` и `versions\`).
2. Запустите установщик перевода:

   ```bat
   python tools\install_ru.py
   ```

   Папка игры определяется автоматически через `libraryfolders.vdf` Steam
   (app id 412020). Если игра найдена неверно, укажите путь явно:

   ```bat
   python tools\install_ru.py --game "F:\SteamLibrary\steamapps\common\Metro Exodus"
   ```

3. Запустите `MetroExodusVR.exe` как обычно.

### Что делает установщик

* Находит все `MetroExodusVR.dll` в `versions\*` (и в корне мода, если он там есть).
* Сохраняет нетронутую копию рядом: `MetroExodusVR.dll.orig`.
* Патчит DLL во временный файл, проверяет результат (`--verify`) и только потом
  заменяет рабочий DLL.
* Записывает (объединяя с существующим) `updater.json`:

  ```json
  {
    "mode": "never",
    "pinned_version": "0.9.0"
  }
  ```

Полезные режимы:

| Команда | Действие |
| --- | --- |
| `--dry-run` | только показать, что будет сделано |
| `--force` | перепатчить из `.orig`, даже если DLL уже пропатчен |
| `--no-pin` | не трогать `updater.json` |
| `--mod-dir <путь>` | папка мода, если она отличается от папки игры |

Повторный запуск безопасен: уже пропатченный DLL пропускается.

## Обновления мода

Патч привязан к конкретной сборке DLL, поэтому перевод и блокировка версии
нужны вместе:

* `mode: never` в `updater.json` отключает автоматическую проверку обновлений;
* `pinned_version` фиксирует версию, которую запускает загрузчик.

Чтобы **осознанно обновить мод**:

1. Запустите `MetroExodusVR.exe --updater-settings` (или удалите `updater.json`)
   и дайте моду скачать новую версию.
2. Снова запустите `python tools\install_ru.py` — он пропатчит новую версию и
   заново зафиксирует её.

Если в новой версии изменились строки, перевод может не примениться к ним:
патчер ищет литералы по содержимому и сайтам ссылок, а не по адресам, но
переименованные строки нужно добавить в `ru/strings.tsv` / `ru/ui2.json`
и пересобрать патч.

## Восстановление оригинального DLL

Скопируйте `MetroExodusVR.dll.orig` поверх `MetroExodusVR.dll` и удалите
`updater.json` (или уберите из него `mode: never`), чтобы вернуть
автообновления. Оригинальный DLL также можно взять из архива релиза.

## Пересборка перевода вручную

```bat
:: проверка таблиц, кодека и плана патча
python tools\validate_ui2.py
python tools\charmap_codec.py --lng work\stable_ru.lng
python tools\apply_ru.py --check

:: сборка пропатченного DLL из оригинального
python tools\apply_ru.py --src work\0.9.0\versions\0.9.0\MetroExodusVR.dll ^
    --out build\MetroExodusVR.dll --verify
```

* `charmap_codec.py` — проверяет, что каждая строка выразима индексами
  charmap, и что байты декодируются обратно в тот же текст.
* `merge_cyrillic.py` — вспомогательный инструмент для TTF (в сборке больше
  не используется: меню рисует шрифт игры).
* `--check` — валидация переводов и построение плана без записи файла.
* `--verify` — после записи повторно читает результат и сверяет стабы и патчи.
* Оригинальный DLL версии 0.9.0 лежит в `work\0.9.0\`; `build\` содержит
  собранный перевод.

## Кодировка строк

Строки нативного меню движок читает **не как текст**, а как однобайтовые
индексы своей таблицы символов — ровно так же, как файлы `.lng`. Поэтому в
`.ru` подписи пишутся индексами из `ru/charmap.txt` (271 запись, взята из
`work/stable_ru.lng`): индекс `< 0xE0` — один байт, большие индексы — два байта
(`idx = first * 0xFF + second - 0xDE41`). UTF-8 и cp1251 движок понимает как
чужие глифы, отсюда были пустые `.notdef`-квадраты.

`Ё`/`ё` в таблице отсутствуют и заменяются на `Е`/`е`; неизвестный символ —
ошибка сборки, а не молчаливый мусор.

Встроенные TTF мода (Inter/Barlow) — это `RCDATA`-ресурсы плашки со ссылками
(«Opened in your browser»), к нативному меню они отношения не имеют: меню
рисует шрифт игры. Поэтому `apply_ru.py` больше **не** подменяет их (флаг
`--fonts` включает старую подмену, `--no-fonts` оставлен для совместимости
и ничего не меняет).

Проверить кодек без DLL и без игры:

```bat
python tools\charmap_codec.py --lng work\stable_ru.lng
python tools\apply_ru.py --check
```

Сборка:

```bat
python tools\apply_ru.py --src work\0.9.0\versions\0.9.0\MetroExodusVR.dll ^
    --out build\MetroExodusVR.dll --verify
```

`--encoding cp1251` собирает старый вариант с Windows-1251 (оставлен, чтобы
сравнивать поведение в игре).

### Почему не хватает одной правки кодировки

Часть строк мод рисует **своим** шрифтом (пакет строк вида
`font_metro_for_menu_main_strings`, US-таблица из 203 записей), а не шрифтом
игры. Для них индексы RU-charmap выглядят как сдвинутый латинский мусор
(`ВКЛ` -> `PJ/`) независимо от кодировки байтов в `.ru`. Разбор и точки
перехвата — в [`ENCODING_NOTES.md`](ENCODING_NOTES.md); там же — как
отличить по поведению в VR, какой шрифт рисует конкретную строку.

## Ограничения

* Лимит длины подписи в нативном меню — 127 байт charmap-индексов (кириллица
  занимает один байт, редкие символы — два).
* В наборе символов локализации нет `Ё`, `—`, `№`; в переводах используются
  `Е`, `–`, `N`/`#`.
* Перевод не трогает ImGui-слой (см. выше).
* Файлы игры не изменяются, кроме добавленных файлов мода; для работы нужен
  VR-шлем.

## Структура

| Путь | Назначение |
| --- | --- |
| `ru/strings.tsv` | 193 подписи: RVA, оригинал, перевод |
| `ru/ui2.json` | popups / options / hints / hintpages |
| `tools/apply_ru.py` | PE-патчер и верификатор |
| `tools/charmap_codec.py` | проверка кодека charmap без DLL |
| `ru/ENCODING_NOTES.md` | разбор пути «байты -> глифы», карта кода, варианты фикса |
| `AGENTS.md` | протокол работы двух агентов (Arena + локальный opencode) |

| `docs/OPENCODE_START.md` | стартовый промпт для локального агента |
| `tools/validate_ui2.py` | проверка `ui2.json` по таблицам DLL и charmap |
| `tools/install_ru.py` | установка в игру, бэкапы, `updater.json` |
| `tools/re_paths.py` | пути для инструментов анализа (см. ниже) |
| `work/` | дампы, xref-ы и промежуточные данные анализа |
| `build/` | собранный `MetroExodusVR.dll` |

### Инструменты анализа вне исходной машины

Скрипты разбора (`disasm_func.py`, `xrefs.py`, `plan.py`, ...) больше не
содержат путей `F:\...`: репозиторий определяется по расположению файла, а
пути к игре и DLL задаются переменными окружения:

| Переменная | Что задаёт | По умолчанию |
| --- | --- | --- |
| `METROEXODUSVR_DLL` | патчируемый `MetroExodusVR.dll` | `work/0.9.0/versions/0.9.0/` |
| `METROEXODUS_EXE` | `MetroExodus.exe` | `%METROEXODUS_GAME%\MetroExodus.exe` |
| `METROEXODUS_GAME` | папка игры | `F:\SteamLibrary\steamapps\common\Metro Exodus` |

Если файла нет, инструмент печатает, чего не хватает, и подсказку про
переменные, а не падает с `FileNotFoundError`.

`work/0.9.0/` (распакованный релиз) и `build/` не хранятся в git — они
воспроизводятся из архива релиза и `tools/apply_ru.py`.
